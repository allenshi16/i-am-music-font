# I AM MUSIC Font

An unofficial I AM MUSIC-inspired layered typography generator built with Next.js.

please visit https://iammusicfont.app

## Features

- Live layered text preview
- Palette, scale, tracking, and stretch controls
- Browser-side PNG and SVG export
- SEO pages for the font explanation and generator guide
- Generated Open Graph image, sitemap, and robots routes
- No account or server upload required

## Development

```bash
npm install
npm run dev
```

## Production

Set the public production origin before building so canonical URLs, structured data, sitemap, and robots use the real domain:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.example npm run build
npm start
```
